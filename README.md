# ProductivityOS AI

Build a modern SaaS web application called "ProductivityOS AI".

ProductivityOS AI is an AI-powered workplace productivity assistant that helps professionals automate daily work tasks using artificial intelligence.

The application should have a premium, enterprise-quality interface similar to Microsoft Copilot, Notion AI, or Linear.

Design Requirements

• Clean, modern SaaS interface

• Professional blue gradient theme

• White cards with soft shadows

• Rounded corners

• Spacious layout

• Excellent typography

• Fully responsive

• Smooth animations and hover effects

• Beautiful icons throughout the application

• Elegant loading animations

• Professional spacing and alignment

Layout

Create a dashboard layout with:

• Left collapsible sidebar

• Top navigation bar

• Main dashboard content

• User profile section

• Notification icon

• Search bar

Sidebar Navigation

Dashboard

Email Generator

Meeting Notes

Task Planner

Research Assistant

AI Chat

Settings

Dashboard

Display a welcome section saying:

"Welcome back"

Heading:

ProductivityOS AI

Subtitle:

Your intelligent workplace assistant.

Include four modern dashboard cards showing:

Emails Generated

Tasks Planned

Meetings Summarized

Research Sessions

Use attractive icons and sample values.

Below the cards create a "Quick Actions" section containing large clickable cards for:

Generate Email

Summarize Meeting

Plan My Tasks

Research Anything

Each card should include:

• Icon

• Title

• Short description

• Modern hover animation

Footer

Display the disclaimer:

"AI-generated content may require human review."

General Requirements

• Responsive desktop and mobile layout

• Clean enterprise appearance

• Smooth transitions

• Premium user experience

• Production-quality UI
